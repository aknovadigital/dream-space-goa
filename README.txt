DREAM SPACE GOA — AKNOVA DIGITAL WEBSITE
=========================================

FILES
- index.html       Main website structure
- styles.css       Visual design and responsive layout
- properties.js    Property listings you can edit
- script.js        Search, filters, property details and WhatsApp forms

PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. Internet is required for Google Fonts and the hosted property photography.

WHATSAPP
The website currently sends enquiries to +91 91750 65537 using WhatsApp click-to-chat.
The visitor reviews and sends the pre-filled message in WhatsApp. No enquiry database or email delivery is configured.

HOW TO ADD OR EDIT A PROPERTY
1. Open properties.js in Notepad or VS Code.
2. Copy one complete property object (from { to }, including the comma as needed).
3. Change id, title, location, type, typeLabel, price, beds, area, features, description and image.
4. Use type: "sale", "rent", or "commercial".
5. Save the file and refresh the website.

IMAGE URL
Use a direct HTTPS image URL. For best results, use high-quality landscape property photos supplied by Dream Space. Replace demo Unsplash images with approved client property photos before launch.

IMPORTANT BEFORE GO-LIVE
- Confirm all listings are currently available.
- Verify exact prices, property specifications, location and usage permissions.
- Replace demo stock photos with the client's actual property photos and obtain permission to use them.
- Confirm business address, email, legal/business details and social links.
- Add a privacy policy and any required real-estate regulatory disclosures after confirming applicable requirements.
- Test WhatsApp enquiries on desktop and mobile.

This is a static front-end website. It has no login/admin panel, server-side form storage, CRM, or database. The forms open WhatsApp with a pre-filled message.
